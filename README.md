# 食谱天下 · Watercolour Recipe 🍯

一款水彩画风的本地化食谱记录工作台，手机优先。

一切数据存在你的浏览器（IndexedDB），没有后端、没有广告、没有 Sidebar。

## ✨ 功能

- 🍱 **16 个分类**：鸡肉 / 猪肉 / 鱼肉 / 虾类 / 鱿鱼 / 螃蟹 / 蚌类 / 蔬菜 / 豆腐 / 鸡蛋 / 甜点 / 烘培 / 咖啡 / 饮料 / 面食 / 其它
- ➕ **无限量食谱**
- 🥣 食材美化排列 · 👩🏻‍🍳 步骤自动编号
- 📷 多张照片（自动压缩，存到本机）
- 🔍 全文搜索
- ❤️ 收藏 / ✏️ 编辑 / 🗑️ 删除
- 📊 每个分类顶部显示食谱数量
- 🖨 A4 打印（所有照片都打印）· 📤 分享为 PDF
- ☁️ 一键备份 / 恢复（含照片 JSON）
- 💾 IndexedDB 本地保存
- ❄️ 雪花飘落动画 · 🍯 水彩风格

## 🚀 直接打开

```bash
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000/
```
